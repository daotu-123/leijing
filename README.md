# 机械工程作品集 · Portfolio

瑞士国际主义风格（Swiss International Style）单页作品集，纯静态 HTML/CSS/JS，无构建、无依赖。

> **当前为占位版**：页面中的姓名、学校、企业名称与照片均已替换为中性占位内容，用于公开预览版式与交互效果。

## 内容结构

- **首屏**：姓名、专业、学校/学历/届次档案表、肖像照、行动入口
- **数据速览**：2027 届 / 2 段工程实习 / 1 项在研创新项目
- **实习经历**：两段工程实习（设备工程师 / 结构工程师）
- **项目流程**：四步闭环（进料 → 清洗 → 定位输送 → 切尾排料）
- **作品**：基于切削与超声波协同的水平去尾清洗一体机
- **能力**：三维设计 / 工程制图 / 设计表达 / 机械基础
- **关于**：自我评价
- **结语**：三条 takeaway

## 本地预览

直接用浏览器打开 `index.html`，不需要服务器。

## 部署

纯静态站点，可直接托管在 GitHub Pages、EdgeOne Pages、Vercel、Netlify 等任意静态托管平台。

### GitHub Pages 部署步骤

1. 仓库 Settings → Pages
2. Source 选择 `Deploy from a branch`
3. Branch 选 `main`，目录选 `/ (root)`
4. 保存后等待约 1 分钟，访问 **https://daotu-123.github.io/leijing/**

## 设计规范

- 单一锚点色：橄榄绿 `#6B8E23`
- 无圆角、无阴影、无渐变，分隔只用 1px 发丝线
- 字重阶梯：越大越细（巨字 200 / 大标题 300 / 正文 400 / 小字 500-600）
- 全程无衬线
- 动效遵循 `prefers-reduced-motion` 降级
